# UniServe-Ruhuna

### Smart Campus Service Management Platform

UniServe-Ruhuna is a full-stack web application developed for the University of Ruhuna to manage campus service requests in a structured and transparent way.

Students and lecturers can report service issues, track request progress, and receive notifications. Administrators can review and assign requests to departments and service staff, while service staff can manage assigned work and update request status until resolution.

### Key Features

- 🔐 JWT-based authentication and role-based access control
- 📝 Campus service request creation and tracking
- 👨‍💼 Admin request review and staff assignment
- 🛠️ Service staff request management
- 🔄 Complete request lifecycle and status history
- 🔔 Notification system
- ♻️ Request reopening for unresolved issues
- 📱 Responsive user interface

### Request Workflow

`PENDING → REVIEWED → ASSIGNED → IN_PROGRESS → RESOLVED → CLOSED`

Requests can also be reopened when further assistance is required.
